# Power BI build guide

The project is in **PBIP** format (text): semantic model in TMDL, report pages in PBIR, both generated by scripts
(`src/build_pbip.py`, `src/build_report_pages.py`). Status: **files generated and cross-checked by script (every field used in the pages
exists in the model); not yet opened in Power BI Desktop.** This guide explains how to open, check and, if needed, rebuild each page by hand.

## 1. Open

1. Power BI Desktop (recent version; PBIP and TMDL preview features enabled if your version asks for it).
2. *File > Open > `powerbi/CentricWorkforce.pbip`*.
3. If the repository is not in `C:\case-study-centric`: *Transform data > Edit parameters > DataFolder* = full path to `data\model\` (with the final `\`).
4. *Refresh*. Expected row counts: see [DATA_MODEL.md](DATA_MODEL.md).
5. Always **save as PBIP** (never `.pbix`, which can carry local paths and metadata).

If the PBIP does not open, create a new report, load the 10 CSV files from `data/model/` with the same names, create the relationships of
DATA_MODEL.md, mark `DimDate` as date table, and paste the measures from `powerbi/measures.dax` into a `_Measures` table.

## 2. Check five measures against SQL

Put a card per measure, with the filters of [KPI_CHECKS.md](KPI_CHECKS.md), and compare:

| Measure | Filter | Expected |
|---|---|---:|
| `[Headcount]` | Month = Sep 2026 | 603 |
| `[Regretted Attrition %]` | Date between 1 Oct 2025 and 30 Sep 2026 | 6.8% |
| `[Attrition % (gross)]` | same | 25.3% |
| `[Utilization %]` | Month = Sep 2026 | 78.4% |
| `[HR vs Finance Gap]` | Month = Sep 2026 | -11 |

Write the Power BI value in the last column of KPI_CHECKS.md.

## 3. Pages (1920 × 1080, theme `CaseStudy_Light`)

Every page: title = conclusion, tag SIMULATED, slicers Site / Department / Month at the top, footer
"Independent case study based on public data · not affiliated with or endorsed by Centric".

### Page 1 · Executive overview
- Cards: `Headcount`, `Regretted Attrition % R12M`, `Voluntary Attrition % R12M`, `Utilization % (closed months)`, `Bench %`, `Open Requisitions`.
- Line chart: X = `DimDate[MonthLabel]`, Y = `Regretted Attrition % R12M`, `Voluntary Attrition % R12M`.
- Column chart: X = MonthLabel, Y = `Headcount`.
- Bar chart: Y axis = `DimOrg[Department]`, X = `Voluntary Attrition %`, `Regretted Attrition %`.
- Line chart: X = MonthLabel, Y = `Utilization % (closed months)`, `Bench %`.

### Page 2 · Attrition deep dive
- Line chart: X = MonthLabel, Y = `Attrition % (gross)`, `Attrition % (excl. transfers)`, `Voluntary Attrition %` (the March 2026 spike).
- Table: `FactMovements[ExitReason]`, `Voluntary Exits`, `Regretted Exits`, sorted by voluntary exits.
- Column chart filtered on Department = Data & Cloud: X = MonthLabel, Y = `Regretted Exits`, `Overtime %` (put Overtime % on the secondary axis by switching to a line and clustered column chart).
- Column chart: X = `FactMovements[TenureBand]`, Y = `Voluntary Exits`.
- Bar chart: Y = `DimGrade[GradeName]`, X = `New-Hire Pay Premium %`.

### Page 3 · Utilization & bench
- Cards: `Utilization % (closed months)`, `Utilization %` (raw), `Timesheet Completeness %`, `Overtime %`, `Month Status`.
- Line chart: X = MonthLabel, Y = `Utilization %`, `Utilization % (closed months)` (shows the cut-off rule).
- Line chart: X = MonthLabel, Y = `Bench %`, Legend = Department, filter `DimOrg[IsBillable]` = 1.
- Line chart: same with `Overtime %`; add a constant line at 0.15 (Analytics pane).
- Table: Department, `Utilization % (closed months)`, `Bench %`, `Overtime %`, `Capacity Hours`.

### Page 4 · Data quality & reconciliation
- Cards: `Duplicate IDs`, `Headcount (raw HRIS)`, `Headcount`, `Finance Headcount`, `HR vs Finance Gap`, `Late Timesheets %`.
- Line chart: X = MonthLabel, Y = `Headcount (raw HRIS)`, `Headcount`, `Finance Headcount`.
- Column chart filtered on Data & Cloud: X = MonthLabel, Y = `Revenue per FTE (as reported)`, `Revenue per FTE`.
- Table: Department, `Revenue`, `Revenue (as reported by finance)`, `Revenue per FTE`, `Revenue per FTE (as reported)`.
- Table filtered on `DimEmployee[IsDuplicateId]` = 1: EmployeeId, MasterEmployeeId, SourceSystem, ValidFrom.

## 4. Test row-level security

*Modeling > View as > DepartmentManager*, tick *Other user* = `head.datacloud@company.example`: every page must show Data & Cloud only.
